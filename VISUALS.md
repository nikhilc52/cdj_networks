## Gephi Processing:

1. Open network file in new project
2. In Data Laboratory, copy `Average Weight` column to Gephi's `Weight` column

### *Visual Creation*

1. [Overview] Run Avg. Weighted Degree
2. [Overview] Nodes -> Size -> Ranking -> Weighted Degree (Min: 10, Max:20)
3. [Overview] Nodes -> Color -> Unique -> Color -> #ABABAB
   1. May be changed to Nodes -> Color -> Partition -> XXXX for subcolorings (see below color list)
4. [Overview] Edges -> Color -> Unique -> Color -> #D4D4D4
5. [Overview] Force Atlas 2
6. [Overview] Expansion (x4)
7. [Preview] Node Labels -> Show Labels -> Font -> Franklin Gothic Medium Size 10 (proportional size off)
8. [Preview] Edges -> Color -> Original
9.  [Preview] Export as PNG
